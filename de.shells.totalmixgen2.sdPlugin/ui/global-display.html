Peak level in dB, as TotalMix sends it (only changes are transmitted, so a silent channel keeps its last value). Refresh the channel list after changing the bus.

Display only. Pressing the key or dial asks TotalMix to re-send all status data (/sendstate) in case the display is stale.

The panel draws a meter with peak hold, a lit connection state, a DSP gauge, or the DURec clock and transport symbol. A custom key image set in Stream Deck replaces it.

Connection (Global OSC slot)

Set one TotalMix Remote Controller's Compatibility (Mode) to "Global OSC". Defaults match controller 2 (7002/9002).

Defaults for new buttons

Stored in Stream Deck itself, so they survive plugin updates. Leave a field empty to use the value shown in grey. These are copied into each button as you add it — buttons already on your Stream Deck keep what they were created with, and are changed under Connection above.

Strip = fader position in the shown bank. To pin this dial to one channel: set Bus, Pin bank start to 0, and Strip to the channel's position on that bus (a stereo pair counts as one strip).

Each press moves the value one step. Place a second button with the opposite direction for a +/− pair. Step: dB for faders and gain, percent of range for FX.

Sets how far one detent travels, since this protocol sends gain as 0..1 with no dB meaning attached and carries no way to identify your interface. The value shown on the key is always TotalMix's own reading, so this only affects how the dial feels, never what it displays.

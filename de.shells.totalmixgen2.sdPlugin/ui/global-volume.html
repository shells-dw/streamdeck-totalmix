Input/playback faders are per-submix (each output has its own mix of them). This picks which one the dial controls; the fader shown in the TotalMix window only follows when that same submix is selected there. The audio changes either way.

Channels are addressed absolutely — no bank or view to pin. A stereo pair is addressed by its left channel. After changing the bus, refresh the channel list.

Gain is input-bus only, steps 1 dB per detent/press within 0–75 dB. On stereo pairs, left and right have separate gains — the "(R)" entries address the right side.

Follows the Control Room's Main Out assignment automatically — the dial always moves whatever output is currently Main Out. Dial press toggles Dim.

Follows the active Control Room monitor automatically. With Speaker B off, the dial controls the output assigned to Main Out; with Speaker B on, it controls Main Out B. Changes made in TotalMix, ARC USB, Stream Deck or any other Global OSC controller are followed from TotalMix's returned state.

Controls one node of the mix matrix: the send level of the source into the chosen output's submix. Dial press solos the node. TotalMix's "Follow Submix" option should be off when using Global OSC.

Applies to keys only. On a Stream Deck+ dial, rotate to adjust; press and touch are set above.

The strip shows the fader position on TotalMix's scale, the mute and solo state, and the channel meter when "Send Level Messages" is enabled for the Global OSC controller. A custom key image or title set in Stream Deck replaces the strip.

Connection (Global OSC slot)

Set one TotalMix Remote Controller's Compatibility (Mode) to "Global OSC". Defaults match controller 2 (7002/9002); the classic actions stay on controller 1 (7001/9001).

Defaults for new buttons

Stored in Stream Deck itself, so they survive plugin updates. Leave a field empty to use the value shown in grey. These are copied into each button as you add it — buttons already on your Stream Deck keep what they were created with, and are changed under Connection above.

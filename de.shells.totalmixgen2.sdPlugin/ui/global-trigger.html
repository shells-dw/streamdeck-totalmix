The key lights up while its snapshot is active — TotalMix signals this over Global OSC even for loads made in the mixer window.

A stereo pair is addressed by its left channel. Refresh the channel list after changing the bus.

Presets are numbered from 1 in the order TotalMix lists them. TotalMix does not report preset names or which preset is loaded, so the key has no state light.

An EQ preset also carries the low cut settings.

A dynamics preset also carries the Auto Level settings.

While recording, TotalMix requires Stop to be pressed twice before it actually stops — a safety against losing a take by accident.

Snapshots and layouts show their number on the face; DURec transport and undo/redo use symbols. Snapshot and transport faces light from TotalMix's state. A custom key image set in Stream Deck replaces the face.

Connection (Global OSC slot)

Set one TotalMix Remote Controller's Compatibility (Mode) to "Global OSC". Defaults match controller 2 (7002/9002).

Defaults for new buttons

Stored in Stream Deck itself, so they survive plugin updates. Leave a field empty to use the value shown in grey. These are copied into each button as you add it — buttons already on your Stream Deck keep what they were created with, and are changed under Connection above.

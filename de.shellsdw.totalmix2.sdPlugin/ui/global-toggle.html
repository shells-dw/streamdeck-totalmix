Channels are addressed absolutely; a stereo pair by its left channel. Refresh the channel list after changing the bus.

Phase is separate per side on stereo pairs — "(R)" entries address the right side. Refresh the list after switching to this parameter.

TotalMix does not report group state over Global OSC, so this button tracks its own presses: it alternates on/off from what it last sent and cannot see changes made in the TotalMix window.

Connection (Global OSC slot)

Set one TotalMix Remote Controller's Compatibility (Mode) to "Global OSC". Defaults match controller 2 (7002/9002).

Defaults for new buttons

Stored in Stream Deck itself, so they survive plugin updates. Leave a field empty to use the value shown in grey. These are copied into each button as you add it — buttons already on your Stream Deck keep what they were created with, and are changed under Connection above.
